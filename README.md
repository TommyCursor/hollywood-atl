# Hollywood ATL — Financial Operations SaaS Dashboard

A production-grade financial operations platform built for a hospitality business. Provides full visibility into revenue, expenses, payroll, events, and partner profit distribution.

## Live Demo
[hollywood-atl-operations.vercel.app](https://hollywood-atl-operations.vercel.app)

## Features
- Real-time KPI tracking — Monthly Sales, Expenses, Net Profit, Tax Collected
- Weekly labor and payroll management (27+ employees)
- Event scheduling with promoter assignment and revenue tracking
- Partner profit-sharing with ownership percentage breakdown
- Sales breakdown by category (Bar, Food, Door/Cover, Hookah)
- Employee scheduling and cash flow management
- Date-range filtering and customizable dashboard views
- Secure authentication with role-based access

## Tech Stack
- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS
- **Backend:** Node.js, PostgreSQL, Prisma
- **Auth:** Clerk / NextAuth
- **Deployment:** Vercel
